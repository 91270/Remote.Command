MCP Server

在 ChatGPT 中添加自定义 MCP Server。

  1. 在 ChatGPT 添加自定义 MCP Server，填入上方地址并选择 OAuth 认证。
  2. ChatGPT 将自动发现 OAuth 端点并完成动态客户端注册与配置回填，无需手动填写 Client ID/Secret。
  3. 跳转至 Gateway 授权页后，使用管理员账号密码登录并确认授权。

添加设备

在要连接的设备上安装 Node.js 24 至 26，然后在终端运行这条命令。

npx --yes --ignore-scripts --package=https://github.com/91270/Remote.Command/releases/download/v0.4.1/remote-command-0.4.1.tgz remote-command remote
